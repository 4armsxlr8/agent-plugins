# 2 つの日付のあいだの営業日数を数えられるようにする

## 使う人と場面
- ジョブストーリー: 申請から締め切りまでの残り日数を表示するとき、土日を除いた日数を出したい。そうすれば利用者が週末を数え違えずに済む
- 使う人: このライブラリを使うアプリ開発者 / 場面: 期限までの残り営業日を表示する処理を書いている / やり遂げたいこと: 2 つの日付のあいだの平日の数を受け取る / 今のやり方: 日付を 1 日ずつ進めるループを毎回書いている

## 課題
営業日数を数える処理が呼び出し側ごとに書かれ、開始日を含めるか、終了日を含めるかが揃わない。

## 解決
開始日を含まず終了日を含む範囲で、土日を除いた日数を返す関数を提供する。

## 要件
- `workdays.business_days_between(start, end)` は `datetime.date` を 2 つ受け取り、営業日数を `int` で返す
- 数える範囲は開始日を含まず終了日を含む (`start` の翌日から `end` まで) = 開始日が平日でも数えない
- 営業日は月曜〜金曜。土曜と日曜は数えない
- `start` と `end` が同じ日なら `0` を返す
- `start` が `end` より後なら `ValueError` を送出する = 負の値や 0 を返さない
- 祝日は考慮しない (平日の祝日も営業日として数える)

## 非機能要件
- 標準ライブラリのみを使う
