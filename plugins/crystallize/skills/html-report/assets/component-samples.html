レポートに使える部品の実物。右上のボタンでライト / ダークを切り替えて、両方で崩れないことを確認する。

  1. 部品の見た目の正本は assets/style.css にあり、レポート側は class を選ぶだけにする。

  3. 見出しの走査目印は絵文字ではなく自動採番 (01, 02 …)。番号は本文と目次の両方に同じ counter で入る。

用語

タスク固有の語だけを <dl class="terms"> に並べる。一般的な技術用語は書かない — 知っている語の説明は読む対象を増やすだけ。無ければ節ごと省く。

無改変層
テンプレートのうち、一字も変えずに貼る CSS / JS のブロック。
昇格
diff の hunk のうち、人間が決裁する対象として選び出したもの。

diff テーブル

diff の表示構造は references/templates.md が正本 (この見本は 1 ファイル分の抜粋)。行番号 2 列 + コード列の 3 列を崩さない。+ と - の記号はコード列に残す — 色だけに頼ると色覚多様性への配慮が抜ける。

重大度は3段。file-head のファイル名の直後に HIGH MED LOW のどれか1つを置く(定義は style.css にあるので追記しない)。

強調と補助テキスト

有彩色は primary 1 色 + 警告 1 色だけ。強調は 1 ページ 1 箇所にする — 2 箇所目を足した時点でどちらも目立たなくなる。背景で目立たせたいときは mark を使う。

補足・注意は .note。本文の流れから外れる但し書きに使う。

折り返したくない語には docs/crystallize/reports/ のように .nowrap を付ける。

引用はこの見た目。素材の原文をそのまま示したいときに使う。
