# 秒数を「1h30m」のような所要時間の文字列に戻せるようにする

## 使う人と場面
- ジョブストーリー: 設定値やログにタイムアウトを表示するとき、秒数ではなく「1h30m」と表示したい。そうすれば読む人が暗算せずに済む
- 使う人: このライブラリを使うアプリ開発者 / 場面: 設定値の確認画面やログ出力を書いている / やり遂げたいこと: 秒数を人が読める所要時間の文字列にする / 今のやり方: 秒数をそのまま表示するか、自前で割り算して組み立てている

## 課題
`parse_duration` で文字列から秒数にはできるが、逆向きの変換がないため、利用者がそれぞれ割り算のコードを書き、表記が揃わない。

## 解決
秒数 (整数) を `h`・`m`・`s` の単位で表した所要時間の文字列に変換する関数を提供し、README の使い方に例を載せる。

## 要件
- `durations.format_duration(seconds)` は 0 以上の整数の秒数を受け取り、所要時間の文字列を `str` で返す
- 単位は `h` (時間)・`m` (分)・`s` (秒) の 3 つで、`h` → `m` → `s` の順に並べる。60 秒以上は分に、60 分以上は時間に繰り上げる (`90` は `"1m30s"`) = 秒や分が 60 以上のまま出力されることはない
- 時間は日に繰り上げない (`90000` は `"25h"`) = `d` の単位は出力しない
- 値が 0 の単位は書かない (`3605` は `"1h5s"`)。ただし秒数が 0 のときは `"0s"` を返す = 空文字列を返さない
- 負の秒数は `ValueError` を送出する
- README.md の「使い方」節に `format_duration` の使用例として、呼び出し `format_duration(3661)` とその結果 `"1h1m1s"` を載せる。既存の `parse_duration` の例は残す

## 非機能要件
- 標準ライブラリのみを使う

## 見た目の正本
- キャンバス: 該当なし
