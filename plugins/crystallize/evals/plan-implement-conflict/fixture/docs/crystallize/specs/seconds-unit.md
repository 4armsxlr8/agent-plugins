# 所要時間の文字列で秒 (`s`) を書けるようにする

## 使う人と場面
- ジョブストーリー: 短いリトライ間隔を設定するとき、「45s」と秒で書きたい。そうすれば分の小数を考えずに済む
- 使う人: このライブラリを使うアプリ開発者 / 場面: リトライ間隔の設定を書いている / やり遂げたいこと: 1 分未満の値を書く / 今のやり方: 1 分未満は書けない

## 課題
`h` と `m` しか書けないため、1 分未満の間隔を設定できない。

## 解決
単位 `s` を追加し、単位のない数字は秒として扱う。

## 要件
- `parse_duration` は単位 `s` (秒) を受け付ける。`h` → `m` → `s` の順に並べる (例: `45s`, `1m30s`)
- 単位のない数字は秒として扱う (`"90"` は 90 を返す) = 単位のない数字が分として解釈されることはない
- 既存の `h`・`m` の解釈は変えない

## 非機能要件
- 標準ライブラリのみを使う

## 見た目の正本
- キャンバス: 該当なし
