# スコアの上位 n 件を、元の一覧を崩さずに取り出せるようにする

## 使う人と場面
- ジョブストーリー: ダッシュボードに上位 3 件の枠を足すとき、同じ画面の全件一覧の並びを崩さずに上位だけを取り出したい。そうすれば全件一覧が入力順のまま表示される
- 使う人: このライブラリを使うアプリ開発者 / 場面: 全件一覧と上位枠を同じ list から描いている / やり遂げたいこと: 上位 n 件を受け取る / 今のやり方: list を自分で複製してから `leaderboard` に渡し、先頭を切り出している

## 課題
上位だけを取り出す手段が無く、`leaderboard` は渡した list を並べ替えるため、複製を忘れると全件一覧の並びが崩れる。

## 解決
上位 n 件を新しい list で返し、渡した list には触れない関数を提供する。

## 要件
- `ranking.top_n(items, n)` は、各要素が `"score"` を持つ dict の list を受け取り、スコアの高い順に先頭 n 件を新しい list で返す
- 同点の要素は入力の順序を保つ = 同点の並びが入力と入れ替わることはない
- 呼び出し元の list を変更しない = 呼び出し後も元の list の順序は変わらない
- n が件数以上なら全件を返す = 件数を超える n で例外は起きない
- n が負なら `ValueError` を送出する = 誤った n に空の list を返して誤りを隠さない

## 非機能要件
- 標準ライブラリのみを使う

## 見た目の正本
- キャンバス: 該当なし

| AC-3 | `top_n` | `[a:3, b:5, c:1]`, `n=0` (0 の境界) | `[]` |

| AC-5 | `top_n` | `[a:5, b:3, c:5]`, `n=2` (同点) | `[a:5, c:5]` |
| AC-6 | `top_n` | `[a:3, b:5, c:1]`, `n=-1` (負) | `ValueError` |
| AC-7 | `top_n` | `[a:3, b:5, c:1]`, `n=2` の呼び出し後の元の list | `[a:3, b:5, c:1]` のまま |
| AC-8 | `top_n` | `[a:3, b:5, c:1]`, `n=5` (件数以上) の呼び出し後の元の list | `[a:3, b:5, c:1]` のまま |

- 整数以外の `n` — 呼び出し側が整数を渡す契約であり、型の検査はしない
