# 所要時間の文字列をコマンドラインから秒数に変換できるようにする

## 使う人と場面
- ジョブストーリー: シェルスクリプトで sleep やタイムアウトの秒数を書くとき、「1h30m」をその場で秒数に直したい。そうすれば暗算の書き間違いが減る
- 使う人: シェルスクリプトを書く開発者 / 場面: スクリプトに待ち時間を書いている / やり遂げたいこと: 人が読める書式の所要時間を秒数の文字列として受け取る / 今のやり方: Python を対話的に起動して `parse_duration` を呼んでいる

## 課題
`parse_duration` はライブラリの関数としてしか使えないため、シェルスクリプトから秒数を得るには Python のコードを書く必要がある。

## 解決
`python3 -m durations.cli <所要時間の文字列>` で秒数を標準出力に出すコマンドを提供する。

## 要件
- `python3 -m durations.cli <所要時間の文字列>` は、引数を既存の `parse_duration` で変換した秒数を 10 進の整数で標準出力に 1 行出し、終了コード 0 で終わる
- 引数が所要時間の文字列として不正なとき (`parse_duration` が `ValueError` を送出するとき) は、標準出力に何も出さず、標準エラーに理由を出して終了コード 1 で終わる = 不正な入力に 0 や部分的な値を出力しない
- 引数の数が 1 つでないとき (なし・2 つ以上) は、標準出力に何も出さず、使い方を標準エラーに出して終了コード 2 で終わる
- 所要時間の文字列の解釈は既存の `parse_duration` に従い、このコマンドで変えない

## 非機能要件
- 標準ライブラリのみを使う

## スコープ外
- 秒数から所要時間の文字列への逆変換
- 標準入力からの読み込み

## 用語
- **所要時間の文字列**: 数字と単位 (`h`・`m`・`s`) の組を順に並べた文字列
