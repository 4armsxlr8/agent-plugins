# 【回答】固定形 — 文書シートからの貼り戻し契約

画面のないタスクの文書シート (`docs/crystallize/specs/<slug>/sheet.html`、`doc-sheet.md`) 専用の契約。画面のあるタスクのラウンドレポート (`round-<n>.html`) は `html-report` の「返信」markdown で答えが戻るので、この形は使わない。

ユーザーが文書シートの [貼り付ける文章を作る] を押すと、この形のテキストがクリップボードとシート内のテキスト欄に出る。ユーザーはそれをターミナルに貼って Enter する。agent はこの形だけを読む。テキストを組み立てるのはシートの無改変層 (`assets/doc-sheet.html` の `CZ-DOC:SCRIPT`) で、シート側が変えることはない。

## 形

```
【回答】<label> ラウンド <round>
Q1. <title>: A — <選択肢の label> / 補足: <自由記述 1 行>
Q2. <title>: (未選択 = お任せ = 推奨 A)
調整パネル: {"itemGap":12,"itemCount":8}
全体へのコメント: <自由記述。複数行あり得る>
---
上の回答を反映して次のラウンドへ進んでください。お任せの項目は推奨案で確定してください。
```

## 規則

- 1 行目 `【回答】<label> ラウンド <round>` と、末尾の `---` + 締めの 1 文は**必須・不変**。`<label>` は `ROUND.label` (spec の slug)、`<round>` は `ROUND.round`。届いた回答の label と round が、いま待っているシートと違えば古い回答なので読まずに聞き直す
- `Qn. <title>: <選択肢 id> — <label>` は択一の答え。`n` は `QUESTIONS` の並び順。補足があれば ` / 補足: <1 行>` が続く (改行は空白 1 つに畳まれる)。推奨は既定で選ばれて表示されるが、ユーザーが押すまでは `(未選択 = お任せ = 推奨 <id>)` として戻る (押した答えだけが `<id> — <label>` になる) — どちらも**推奨で確定する**。推奨が無い問いの未選択は `(未選択 = お任せ)`
- `調整パネル:` は `TWEAKS` (値の帯) の最終値の 1 行 JSON (flat な `{key: value}`)。`TWEAKS` が空のシートでは出ない。ここに出た値が確定値の正本になる
- `全体へのコメント:` は自由記述で、次の `---` までが本文。**空でも `(なし)` で必ず出る** (本文の終端を `---` で決めるため、この行だけは省略しない)。前提への異議は本文の先頭に `前提 Pn (<本文>) への異議: …` として 1 行ずつ入り、本文中の `---` だけの行は `- - -` に置き換えられている。設計を変える指摘は design tree に足し、別案の提示は次のラウンドの問いにする
- それ以外の空の項目は行ごと出ない (`/ 補足:` は補足が空なら付かず、`調整パネル:` は該当が無ければ行ごと無い)
- シートを改造しても、この形を崩さない — 読む側 (spec スキル) は 1 つの読み方しか持たない
