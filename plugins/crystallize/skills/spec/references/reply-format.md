# 【回答】固定形 — ラウンドシートからの貼り戻し契約

ユーザーがラウンドシート (`docs/crystallize/specs/<slug>/mock.html`) の [貼り付ける文章を作る] を押すと、この形のテキストがクリップボードとパネル内のテキスト欄に出る。ユーザーはそれをターミナルに貼って Enter する。agent はこの形だけを読む。テキストを組み立てるのはモックキットの無改変層 (`assets/mock-kit.html` の `CZ-KIT:SCRIPT`) で、モック側が変えることはない。

## 形

```
【回答】<label> ラウンド <round>
Q1. <title>: A — <選択肢の label> / 補足: <自由記述 1 行>
Q2. <title>: (未選択 = お任せ = 推奨 A)
見ていた案: B · <案名> / 状態: many / 端末: phone
調整パネル: {"itemGap":12,"itemCount":8,"accentColor":"#3f6ad8","density":"default"}
全体へのコメント: <自由記述。複数行あり得る>
---
上の回答を反映して次のラウンドへ進んでください。お任せの項目は推奨案で確定してください。
```

## 規則

- 1 行目 `【回答】<label> ラウンド <round>` と、末尾の `---` + 締めの 1 文は**必須・不変**。`<label>` は `ROUND.label` (spec の slug)、`<round>` は `ROUND.round`。届いた回答の label と round が、いま待っているシートと違えば古い回答なので読まずに聞き直す
- `Qn. <title>: <選択肢 id> — <label>` は択一の答え。`n` は `QUESTIONS` の並び順。補足があれば ` / 補足: <1 行>` が続く (改行は空白 1 つに畳まれる)。未選択は `(未選択 = お任せ = 推奨 <id>)` — **推奨で確定する**。推奨が無い問いの未選択は `(未選択 = お任せ)`
- `見ていた案:` は貼り戻しの瞬間に表示されていた案・状態・端末。案が 0 のシートでは出ない。案の採否を問う `Qn.` で**明示的に選ばれた答え**と食い違っていたら (B を選んで A を見ていた等) 確定せずに問い直す。未選択 (お任せ) の問いは食い違いとみなさない — B を見に行ってから推奨の A に任せるのは普通の終わり方で、そこで問い直すと削った往復が戻る
- `調整パネル:` は `TWEAKS` の最終値の 1 行 JSON (flat な `{key: value}`)。`TWEAKS` が無いシートでは出ない。ここに出た値が「モック確定・実機で再確認」の値の正本になる
- `全体へのコメント:` は自由記述で、次の `---` までが本文。**空でも `(なし)` で必ず出る** (本文の終端を `---` で決めるため、この行だけは省略しない)。設計を変える指摘は design tree に足し、別案の提示は次のラウンドの問いにする
- それ以外の空の項目は行ごと出ない (`/ 補足:` は補足が空なら付かず、`見ていた案:` と `調整パネル:` は該当が無ければ行ごと無い)
- モックキットを改造しても、この形を崩さない — 読む側 (spec スキル) は 1 つの読み方しか持たない
