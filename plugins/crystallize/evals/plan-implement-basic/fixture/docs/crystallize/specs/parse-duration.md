# 「1h30m」のような所要時間の文字列を秒数に変換できるようにする

## 使う人と場面
- ジョブストーリー: 設定ファイルにタイムアウトを書くとき、秒数を暗算せずに「1h30m」と書きたい。そうすれば書き間違いが減る
- 使う人: このライブラリを使うアプリ開発者 / 場面: 設定値を読み込む処理を書いている / やり遂げたいこと: 人が読める書式の所要時間を秒数で受け取る / 今のやり方: 秒数を手で計算して書いている

## 課題
所要時間を秒数でしか受け取れないため、設定を書く人が暗算し、桁を間違える。

## 解決
`h`・`m`・`s` の単位を並べた文字列を秒数 (整数) に変換する関数を提供する。

## 要件
- `durations.parse_duration(text)` は所要時間の文字列を受け取り、秒数を `int` で返す
- 単位は `h` (時間)・`m` (分)・`s` (秒) の 3 つ。数字と単位の組を 1 つ以上、`h` → `m` → `s` の順に並べる (例: `1h30m`, `45s`, `1h1m1s`, `90m`) = 順序が違う文字列 (`30m1h`) は受け付けない
- 各単位の値に上限はない (`90m` は 5400 を返す) = 繰り上げの正規化はしない
- 空文字列、単位のない数字、未知の単位、順序違い、同じ単位の重複は `ValueError` を送出する = 不正な入力に 0 や部分的な値を返さない

## 非機能要件
- 標準ライブラリのみを使う

## 見た目の正本
- キャンバス: 該当なし

## スコープ外
- 秒数から文字列への逆変換

## 用語
- **所要時間の文字列**: 数字と単位 (`h`・`m`・`s`) の組を順に並べた文字列
