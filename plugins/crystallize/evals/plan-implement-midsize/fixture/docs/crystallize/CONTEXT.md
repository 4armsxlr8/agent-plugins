# 請求ライブラリ

このライブラリが扱う請求書と金額に関する語。

## 用語

- **帳簿**: 請求書と監査ログをまとめて持つもの。コード上の識別子は `book`
- **値引き**: 請求書全体にかける減額。コード上の識別子は `allowance`。 _使わない語_: 割引, discount
- **純額**: 値引きを按分したあとの税抜金額。コード上の識別子は `net`
- **請求額**: 純額の合計と税額の合計の和。コード上の識別子は `total`
- **返金**: 全額入金済みの請求書の明細を、数量を指定して顧客へ戻すこと。コード上の識別子は `refund`。 _使わない語_: 払い戻し, reimbursement
