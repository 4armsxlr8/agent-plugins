# テキストの語数を数える関数と、ファイルの語数を表示するコマンドを用意する

## 使う人と場面
- ジョブストーリー: 原稿の語数の上限を確かめるとき、ファイルを渡すだけで語数を知りたい。そうすれば手で数えずに入稿前の確認を済ませられる
- 使う人: 原稿を書く人と、このライブラリを使うアプリ開発者 / 場面: 入稿前に原稿の長さを確かめている / やり遂げたいこと: 語数を得る / 今のやり方: エディタの表示を目で見て数えている

## 課題
語数を数える手段がライブラリにもコマンドにもないため、呼び出し側ごとに数え方を書き、空白の扱いが食い違う。

## 解決
空白で区切った語数を返す関数と、ファイルを渡すとその語数を表示するコマンドを提供する。

## 要件
- `wordcount.count_words(text)` は文字列を受け取り、空白 (スペース・タブ・改行) で区切った語の数を `int` で返す。連続する空白と前後の空白は語を増やさない
- `python3 -m wordcount.cli <ファイル>` はファイルを UTF-8 で読み、その語数だけを 1 行で標準出力に書いて終了コード 0 で終わる
- ファイルが存在しないときは、その旨を標準エラーに書いて終了コード 1 で終わる = 標準出力には何も書かない

## 非機能要件
- 標準ライブラリのみを使う

## 見た目の正本
- キャンバス: 該当なし

## 受け入れ基準 (テストケース表)
| ID | seam | ケース | 期待結果 |
|---|---|---|---|
| AC-1 | `count_words` | `"hello world"` | `2` |
| AC-2 | `count_words` | `""` (空) | `0` |
| AC-3 | `count_words` | `"  a\n\tb   c "` (連続・前後の空白、タブ、改行) | `3` |
| AC-4 | `python3 -m wordcount.cli` | 中身が `"one two three\n"` のファイルを渡す | 標準出力 `3`、終了コード 0 |
| AC-5 | `python3 -m wordcount.cli` | 存在しないパスを渡す | 標準出力は空、標準エラーにメッセージ、終了コード 1 |

テストしないと決めたもの:
- 全角スペース — 区切りとして扱うかを決めておらず、原稿は半角スペースで書かれている
- 標準エラーのメッセージの文面 — 人が読むためのもので、呼び出し側は終了コードで判定する
