# 記事タイトルから URL 用の slug を作れるようにする

## 使う人と場面
- ジョブストーリー: ブログの記事を追加するとき、タイトルから URL の末尾を自動で作りたい。そうすれば URL を手で考えずに済み、表記揺れも起きない
- 使う人: このライブラリを使うブログ運営者向けアプリの開発者 / 場面: 記事の保存処理を書いている / やり遂げたいこと: タイトルから URL に使える文字列を得る / 今のやり方: 運営者が URL の末尾を手で入力している

## 課題
URL の末尾を手で入力しているため、大文字や記号が混ざったり、長すぎる URL ができたりする。

## 解決
タイトルを小文字・ハイフン区切りの短い文字列に変換する関数を提供する。

## 要件
- `slugs.slugify(title)` は記事タイトルを受け取り、URL 用の slug を `str` で返す
- ASCII の英字は小文字にする = 大文字を含む slug は返さない
- 空白 (連続する空白を含む) はハイフン 1 つに置き換える
- 記号を取り除いたあとに連続したハイフンは 1 つにまとめ、先頭と末尾のハイフンは取り除く = `--` を含む slug や、ハイフンで始まる slug は返さない
- ASCII の英数字・空白・ハイフン以外の文字は取り除く = 記号が slug に残ることはない
- 結果は 40 文字以内に切り詰め、切った位置の末尾に残ったハイフンは取り除く = 41 文字以上の slug や、ハイフンで終わる slug は返さない
- 変換後に空になる入力は `ValueError` を送出する = 空の slug は返さない

## 非機能要件
- 標準ライブラリのみを使う

## 見た目の正本
- キャンバス: 該当なし

## 受け入れ基準 (テストケース表)
| ID | seam | ケース | 期待結果 |
|---|---|---|---|
| AC-1 | `slugify` | `"Hello World"` | `"hello-world"` |
| AC-2 | `slugify` | `"Python  3.9  Release"` (連続する空白・記号) | `"python-39-release"` |
| AC-3 | `slugify` | `"Hello, World!"` (記号) | `"hello-world"` |
| AC-4 | `slugify` | `"Pre-release Notes"` (元からあるハイフン) | `"pre-release-notes"` |
| AC-5 | `slugify` | `"!!!"` (記号だけ) | `ValueError` |
| AC-6 | `slugify` | `""` (空) | `ValueError` |
| AC-7 | `slugify` | `"  Hello - World & Co  "` (前後の空白・連続するハイフン) | `"hello-world-co"` |

テストしないと決めたもの:
- 日本語などの非 ASCII 文字 — 「英数字・空白・ハイフン以外を取り除く」と同じ経路になり、AC-3 と別の行を立てる価値がない
- 文字列以外の入力 — 呼び出し側が文字列を渡す契約であり、型の検査はしない

実機確認に委ねる基準 (UI・見た目など TDD 対象外で挙動ゲートに委ねるもの):
- なし

## スコープ外
- 既存の slug との重複の検出

## 用語
- **slug**: 記事の URL の末尾に置く、小文字の英数字とハイフンだけからなる文字列
